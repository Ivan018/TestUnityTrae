# 通用设计规范 - UGUI 版本

## 1. 设计原则

### 1.1 一致性原则
- 界面元素的外观和行为保持一致
- 相同功能的按钮、图标、输入框使用统一样式
- 交互反馈保持一致（悬停、点击、选中状态）

### 1.2 清晰性原则
- 信息层次分明，重点突出
- 使用适当的间距和对齐方式
- 文字清晰可读，对比度适中

### 1.3 易用性原则
- 操作流程简洁明了
- 按钮尺寸适合点击（移动端最小44x44px）
- 提供明确的操作反馈

## 6. 组件规范

## 7. 布局规范

### 7.1 页面布局
- 全屏布局：宽度100%，高度100%
- 固定宽度布局：最大宽度1200px，居中对齐

### 7.2 登录页布局（左右分栏）
- 左侧：55%宽度，品牌展示区
- 右侧：45%宽度，登录表单区

### 7.3 通用布局规则
- 使用Canvas作为根容器
- 使用RectTransform进行定位
- 使用Layout组件进行自动布局

## 9. 状态反馈规范

### 9.1 加载状态
- 使用loading动画
- 禁用交互按钮
- 显示加载提示

### 9.2 成功状态
- 显示成功图标
- 显示成功提示文字
- 可自动关闭或手动关闭

### 9.3 错误状态
- 显示错误图标
- 显示错误提示文字
- 提供重试按钮

## 10. 响应式规范

### 10.1 屏幕尺寸适配
| 屏幕尺寸 | 布局策略 |
| :--- | :--- |
| < 768px | 单列布局 |
| 768px - 1200px | 双列布局 |
| > 1200px | 三列布局 |

### 10.2 适配方式
- 使用Canvas Scaler组件
- 设置合适的Reference Resolution
- 使用相对布局而非绝对定位

## 11. UGUI 实现指南

### 11.1 创建登录页面步骤

#### 步骤1：创建Canvas
- 创建新的Canvas对象
- 设置Canvas Scaler的Reference Resolution为1920x1080
- 设置UI Scale Mode为Scale With Screen Size

#### 步骤2：创建背景
- 添加Image作为全屏背景
- 设置颜色或使用背景图

#### 步骤3：创建左侧品牌区
- 添加Panel作为容器
- 设置宽度为屏幕宽度的55%
- 添加品牌Logo（Image）
- 添加品牌名称（Text）
- 添加品牌描述（Text）

#### 步骤4：创建右侧登录区
- 添加Panel作为容器
- 设置宽度为屏幕宽度的45%
- 添加登录卡片（Panel）
- 在卡片内添加：
  - 登录标题（Text）
  - 账号输入框（InputField）
  - 密码输入框（InputField，设置为密码类型）
  - 记住密码（Toggle + Text）
  - 登录按钮（Button）

#### 步骤5：添加脚本
- 创建LoginController脚本
- 绑定输入框、Toggle和Button组件
- 实现登录逻辑和记住密码功能

### 11.2 组件命名规范
| 组件类型 | 命名前缀 | 示例 |
| :--- | :--- | :--- |
| Button | btn_ | btn_login |
| InputField | input_ | input_account |
| Toggle | toggle_ | toggle_remember |
| Text | txt_ | txt_title |
| Image | img_ | img_logo |
| Panel | panel_ | panel_left |
